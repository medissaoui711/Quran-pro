## 🌟 نظرة عامة (Overview)

**Quran Pro** هو تطبيق ويب تقدمي (Progressive Web Application) متكامل وفاخر يهدف إلى تقديم تجربة قراءة واستماع وتدبر فريدة للقرآن الكريم. تم بناء التطبيق بأحدث تقنيات الويب الحديثة ليعمل بسرعة فائقة وبدون انقطاع، مع إمكانية التثبيت المباشر على الهواتف الذكية وأجهزة الحاسوب والعمل في وضع عدم الاتصال (Offline Support).

---

## ✨ المميزات الرئيسية (Key Features)

### 📖 القراءة والمصحف الشريف
- **الرسم العثماني المعتمد**: عرض صفحات المصحف الشريف بدقة عالية وفق طبعة مجمع الملك فهد لطباعة المصحف الشريف.
- **تقليب وإيماءات ذكية (Gesture Engine)**: دعم السحب الطبيعي باللمس والفأرة متوافق 100% مع اتجاه القراءة العربي (RTL) لمحاكاة تقليب صفحات المصحف الورقي بسلاسة.
- **تخصيص كامل للقراءة**: أوضاع قراءة متعددة (الوضع الليلي الفاخر، الوضع النهاري المريح، والوضع الداكن الخاص بشاشات OLED).
- **الوصول السريع والفهرس الذكي**: فهرس شامل للسور، الأجزاء، الأحزاب، الأرباع، مع خاصية البحث اللحظي بالاسم والآية.

### 🎧 التلاوة والاستماع الصوتي المتزامن
- **نخبة من كبار القراء**: الاستماع إلى أشهر مشاهير القراء في العالم الإسلامي بجودة صوت نقية وعالية.
- **التظليل التفاعلي للآيات**: تظليل ومزامنة الآية المقروءة آنياً أثناء الاستماع مع إمكانية تكرار الآيات لتسهيل الحفظ والمراجعة.
- **مشغل صوتي عائم ومتقدم**: يدعم استمرار التشغيل في الخلفية، مؤقت النوم، والتحكم في سرعة التلاوة.

### 📚 التفسير والترجمات والتدبر
- **أمهات كتب التفسير**: التفسير الميسر، تفسير ابن كثير، السعدي، والقرطبي بضغطة زر واحدة.
- **الترجمات العالمية**: دعم ترجمة معاني الآيات لعدة لغات عالمية لغير الناطقين بالعربية.
- **الإعراب والمعاني اللغوية**: بيان معاني المفردات الغريبة وإعراب الآيات للمتعلمين والباحثين.

### 🕌 الخدمات الإسلامية المساعدة
- **مواقيت الصلاة الدقيقة**: حساب مواقيت الصلوات اليومية وفق موقعك الجغرافي وطرق الحساب الفقهية المعتمدة مع تنبيهات الأذان.
- **اتجاه القبلة التفاعلي**: بوصلة دقيقة لتحديد اتجاه القبلة المشرفة بدقة وسهولة.
- **أذكار المسلم وحصن المسلم**: باقة شاملة من أذكار الصباح والمساء، أذكار النوم، وبعد الصلاة مع عداد رقمي ذكي.
- **المسبحة الإلكترونية التفاعلية**: مسبحة ذكية لحفظ التسبيحات والإحصائيات اليومية مع ردود فعل اهتزازية وصوتية.
- **العلامات المرجعية والملاحظات**: حفظ مواضع القراءة ومزامنة الختمات والملاحظات الشخصية محلياً.

## 🛠️ التقنيات المستخدمة (Tech Stack)

| التقنية / المكتبة | الغرض والاستخدام |
| :--- | :--- |
| **React 19** | أحدث إصدار لمكتبة واجهة المستخدم لبناء بنية تفاعلية فائقة الأداء |
| **TypeScript** | أمان الأنماط ومنع الأخطاء البرمجية أثناء وقت التطوير |
| **Tailwind CSS v4** | تصميم أنيق وعصري مبني بنظام الأدوات (Utility-first CSS) عالي الكفاءة |
| **Vite 6** | حزمة البناء الأسرع عالمياً مع دعم التجميع الأمثل للأصول |
| **Motion (Framer Motion)** | حركات وانتقالات انسيابية وتفاعلية طبيعية بين الصفحات |
| **Lucide Icons** | أيقونات خطية دقيقة وحديثة متوافقة مع المعايير القياسية |
| **Service Workers & PWA** | التخزين المؤقت، العمل دون اتصال، وتثبيت التطبيق على الشاشة الرئيسية |
| **Cloudflare Pages / Workers** | الاستضافة السحابية العالمية السريعة والتوزيع عبر شبكة CDN الأسرع عالمياً |

## 🚀 التشغيل المحلي والتطوير (Local Development)

### المتطلبات المسبقة:
- تثبيت **Node.js** (الإصدار 18 فما فوق) أو **Bun**.
- تثبيت مدير الحزم **npm** أو **bun** أو **pnpm**.

### خطوات التثبيت والتشغيل:

1. **استنساخ المستودع (Clone Repository)**:
   ```bash
   git clone https://github.com/medissaoui711/Quran-pro.git
   cd Quran-pro
   ```

2. **تثبيت الحزم والاعتماديات (Install Dependencies)**:
   ```bash
   npm install
   # أو عبر Bun
   bun install
   ```

3. **تشغيل الخادم المحلي للتطوير (Start Dev Server)**:
   ```bash
   npm run dev
   # أو عبر Bun
   bun run dev
   ```

4. **فتح التطبيق**:
   افتح المتصفح على العنوان التالي:
   `http://localhost:3000` (أو الرابط المعروض في الطرفية).

## ☁️ النشر على Cloudflare Pages (Deployment Guide)

المشروع مهيأ ومعد بالكامل وجاهز للنشر المباشر عبر **Cloudflare Pages** بفضل ملفات الإعداد التلقائية:

### إعدادات البناء الموصى بها في لوحة Cloudflare:
- **Framework Preset**: `Vite`
- **Build Command**: `npm run build` *(أو `bun run build`)*
- **Deploy Command**: `npx wrangler deploy` *(أو تترك فارغة وفق نوع المشروع)*
- **Build Output Directory**: `dist`
- **Root Directory**: `/`

### ملفات التكوين المضمنة:
- `wrangler.jsonc` / `wrangler.json`: لضبط محاكاة تطبيق الصفحة الواحدة (`single-page-application`) وتحديد مسار المخرجات `./dist`.
- `public/_headers`: لضبط ترويسات الأمان المتقدمة والتخزين المؤقت طويل الأمد للأصول المجمعة لضمان أقصى سرعة تحميل.

## 📂 هيكل المشروع (Project Structure)

```text
├── public/                # الأصول الثابتة، الأيقونات، ملفات الترويسات والـ Manifest
│   ├── icons/             # أيقونات التطبيق بدقات متعددة
│   ├── _headers           # ترويسات أمان وكاش Cloudflare
│   ├── favicon.svg        # شعار التطبيق
│   ├── manifest.webmanifest # تعريف تطبيق الويب التقدمي (PWA)
│   └── sw.js              # ملف Service Worker للتشغيل بدون إنترنت
├── src/
│   ├── components/        # مكونات الواجهة التفاعلية (المصحف، المشغل، الفهرس، الأذكار...)
│   │   ├── mobile/        # واجهات ومكونات الهواتف والشاشات الصغيرة
│   │   └── ...
│   ├── hooks/             # خطافات التفاعل المنطقية (مثل useQuranSwipe للسحب والتقليب)
│   ├── types/             # تعريفات TypeScript ونماذج البيانات
│   ├── utils/             # دوال المعالجة المساعدة والحسابات الفلكية
│   ├── App.tsx            # المكون الجذري للتطبيق
│   ├── main.tsx           # نقطة الانطلاق الرئيسية لـ React
│   └── index.css          # استيرادات وتخصيصات Tailwind CSS
├── wrangler.jsonc         # إعدادات نشر Cloudflare Pages المتقدمة
├── wrangler.json          # النسخة المطابقة لإعدادات النشر
├── package.json           # الحزم، التبعيات، وأوامر التشغيل
├── tsconfig.json          # إعدادات مترجم TypeScript
└── vite.config.ts         # إعدادات حزمة البناء Vite وإضافات React و Tailwind
```
